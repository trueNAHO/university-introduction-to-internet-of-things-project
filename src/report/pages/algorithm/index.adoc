AHP:
AHP uses pairwise comparisions to decide an end goal in our case the optimal
room. To use AHP we first have to choose a set of criteria and a set of alternatives.

Room facilities has several sub-criteria which are facilities that students or
teachers need in their room.

The goal of AHP is to compare each criteria to each other and each alternative
to every other alternative for every criteria. To do the comparision we will use 
this table: (insert image [1])

We decide for the following judgements:

|A          |B            |More important|Intensity|
|Temperature|Co2 Level    |B             |3        |
|Temperature|air quality  |B             |5        |
|Temperature|room facility|B             |9        |
|Co2 Level  |air quality  |B             |3        |
|Co2 Level  |room facility|B             |9        |
|air quality|room facility|B             |5        |

Gives use the matrix:
|             |Temperature|Co2 Level|air quality|room facility|
|Temperature  |1          |3        |5          |9            |
|Co2 Level    |1/3        |1        |3          |9            |
|air quality  |1/5        |1/3      |1          |5            |
|room facility|1/9        |1/9      |1/5        |1            |
